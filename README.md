# Nim Player

Nim Player 是一款正在开发中的 Windows 桌面视频播放器，基于 Tauri、React、Rust 和 MPV 构建。

## 主要功能

- 本地视频及网络视频播放
- WebDAV、AList、OpenList 等网络数据源
- 影视媒体库管理与 TMDB 元数据刮削
- 字幕管理及播放器参数调整
- 剧集管理、播放进度记录及自动连播
- 在线弹幕功能（开发中）

## 在线弹幕开发计划

计划接入弹弹play开放弹幕网络 API，实现：

- 根据影视作品、季度及集数自动匹配在线弹幕
- 手动搜索并选择弹幕资源
- 在线弹幕获取、缓存与显示
- 弹幕与视频播放、暂停、进度跳转及倍速同步
- 弹幕大小、透明度、密度、显示区域及时间偏移调整

项目目前处于个人开发测试阶段，暂未正式发布。

本仓库用于展示项目介绍及开发计划，不包含完整应用源代码。
