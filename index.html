围绕观看体验而构建

以下为项目功能方向。部分能力仍处于持续开发和验证阶段。

▶

本地与网络播放

以 MPV 为播放基础，围绕本地文件、WebDAV、AList 和 OpenList 等网络媒体场景持续优化体验。

▦

影视媒体库

围绕电影、电视剧与动漫的作品归类、剧集整理、播放进度及 TMDB 元数据展示逐步完善。

≡

精简播放器控制

进度预览、音轨与字幕选择、倍速、片头片尾跳过、窗口状态等控制集中在播放器界面。

在线弹幕接入计划

计划申请并遵守弹弹play开放弹幕网络 API 的授权、接口规范与配额要求。

01
自动匹配与手动搜索

根据作品名称、季度、集数和现有媒体信息匹配对应弹幕库；匹配不确定时由用户选择。

02
在线获取与合理缓存

按需获取在线弹幕，复用缓存以减少重复请求。不提供大规模抓取、转售或下载弹幕库的功能。

03
跟随播放器时间轴同步

弹幕将以 MPV 实际播放时间为准，在暂停、Seek、倍速和切集时保持正确同步。

04
可调节的弹幕显示

规划显示开关、大小、透明度、密度、显示区域和时间偏移等参数。暂不开发本地弹幕导入。

关于 Nim Player

Nim Player 是独立开发中的 Windows 桌面播放器，目前用于个人功能开发与测试，尚未正式公开发布。此网站用于项目介绍及第三方开放 API 的应用审核，不包含应用源码、用户媒体或密钥。
